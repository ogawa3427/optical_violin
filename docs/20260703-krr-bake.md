## 焼き込み表現（サイズの要点）

素朴に「per-k のスケール済みサポートベクトル」を焼くと
Σ_k n·(k+1) ≈ 129×5460 ≈ 70万 float で肥大する。そこで:

- **StandardScaler の mean はカーネル距離で相殺される**ことを利用:
  `||(x−m)/s − (X_i−m)/s||² = Σ_j ((x_j − X_ij)/s_j)²`
- 焼くのは **生 pad 済み Δt 行列 `KRR_X`(129×104) を全 k で共有** + 三角バンク
  `KRR_SCALE`(5460) + `KRR_ALPHA`(104×129) + `KRR_GAMMA`(104)
  ≈ **3.2万 float ≈ 130KB**（Ridge 時代 1.6万 float の約 2 倍で収まる）

推論（`m62.cpp: score_at_k`）:
`pred = clip(Σ_i α[k][i]·exp(−γ[k]·Σ_{j≤k}((obs[j]−X[i][j])/scale[k][j])²), ±1)`

1 パルスあたり最悪 129×104 ≈ 1.3万 積和 + 129 expf。ESP32-S3 の FPU で余裕
（バッチ全 prefix 計算は重いが、実機は CausalEngine の 1 k/パルスのみ）。
